Research prototype

Catching sleeper instructions in an AI agent's memory, from the inside.

Attackers plant instructions in agent memory that wait for a trigger, and output monitors see nothing until it fires.

See it work Read the results

Same words out. Different inside.

On the two dormant turns all three agents answer the same way, so an output monitor sees nothing. The probe reads the model's activations and scores the planted notes high from turn 1.

Notes & Limitations

Mechanism: Zero-Token Residual Stream Probe

Provider-side threat model: The defender operates the model inference API and observes only the incoming prompt and the model's internal residual activations. No runtime code sandbox, behavioral log inspector, or prompt text keyword filtering is required.
