How It Works

      

        Provider-side threat model: The defender operates the model inference API and observes only the incoming prompt and the model's own intermediate activations. No external execution monitor or parser is required.
      


      

        

          Step 1
          
Prompt Ingestion

          

            An agent request arrives containing context, past interaction history, and retrieved persistent memory entries.
          

        

        

          Step 2
          
Internal Activation Read

          

            As the model processes the context, we extract the residual stream vectors at the end of the memory tool result token position (averaged across layers 14–19 of 24).
          

        

        

          Step 3
          
Zero-Token Pre-emption

          

            A lightweight linear probe evaluates the activation state and scores risk before the model writes a single output token.
